⚡ Thao tác nhanh
📖 Hướng dẫn sử dụng nhanh
1. Thêm/Sửa/Xóa nội dung: Chọn mục ở thanh bên trái (Từ vựng, Hội thoại, Bài tập). Bấm nút + Thêm màu xanh để tạo mới, hoặc biểu tượng ✏️ để sửa.
2. Dữ liệu lưu ở đâu? Tự động lưu trong trình duyệt (localStorage). Lần sau mở lại vẫn còn nguyên.
3. Cập nhật lên web học: Bấm nút Xuất data.js ở trên cùng 👆 — tải file về, chép đè vào js/data.js của web chính.
4. Nhập từ file cũ: Vào mục "Xuất / Nhập" để tải lên file data.js đã có sẵn.

Xuất & Nhập dữ liệu
Đồng bộ nội dung với web học chính.
📤 Xuất dữ liệu ra file

Tải file data.js về máy. Sau đó chép đè vào thư mục js/data.js của web học để cập nhật.

📥 Nhập dữ liệu từ file

Chọn file data.js đã có để nhập vào. Lưu ý: thao tác này sẽ ghi đè dữ liệu hiện tại.

⚠️ Vùng nguy hiểm

Đặt lại toàn bộ về dữ liệu gốc ban đầu. Mọi thay đổi sẽ bị mất vĩnh viễn.
